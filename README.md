# 五行（暂定名）

像素小人行走于水墨山河的五行 RTS。三大国家（离国·火 / 朔国·水 / 大衍·土），对战 + 魔兽式剧情战役双模式。

- 设计与规划：[PLAN.md](PLAN.md)（机制与路线图）· [LORE.md](LORE.md)（世界观设定集）
- 引擎：Godot 4.7（GDScript）

## 运行

1. 用 Godot 4.7 打开本目录的 `project.godot`
2. F5 运行 `TestMap.tscn`（M0 可操控骨架）；或在文件面板打开 `maps/StyleTarget.tscn` 按 F6 查看**风格定妆照**

## M0 操作

| 操作 | 按键 |
|------|------|
| 点选 / 框选（Shift 加选） | 左键 |
| 移动指令 | 右键 |
| 平移 | WASD / 方向键 / 屏幕边缘 |
| 缩放 | 滚轮（以鼠标为锚） |
| 小地图跳转 | 左键点小地图 |

## 说明

- M0 的所有美术均为**程序化生成占位**（宣纸 shader、程序水墨远山、代码像素小人），正式美术在 M2~M3 替换
- 输入动作由 `systems/input_bootstrap.gd` 在启动时注册，M3 迁入项目设置
- 单位/地形为代码构建的薄场景（thin scene），便于 AI 编写与版本管理；M1 起逐步迁移为标准场景
